Complete walkthrough · assumes nothing

Getting started, from nothing.

You play a game on your desktop. Later you want to carry on from your laptop, or your Steam Deck — and unless the game supports Steam Cloud, your progress stays where it was. This walks through fixing that, start to finish, explaining every term as it comes up.

First, what it actually does

Two things, and two it deliberately doesn't.

🗂️

Keeps a copy of every change

When a game writes a save, OpenSave records how the folder looked at that moment. That's a snapshot, and you can go back to any of them.

🔄

Sends the change to your other devices

Directly, machine to machine. Only the parts of the file that changed are sent, so it's quick even on a big save.

🚫

No account, no server

Nothing is uploaded anywhere unless you switch on cloud backup yourself. There's nothing to sign up for and nothing to cancel.

🛑

Never overwrites without asking

If two devices changed the same save independently, it stops and asks you rather than picking one. Nothing is lost while you decide.

It works for any game whose save is a folder or a file on disk — bought anywhere, or installed from outside a store entirely. Emulators too.

Setting up

Install it, then find your saves.

Do this on each device you want to sync — they all need the app.

1

Download and run it

On Windows, download OpenSave.exe and run it. There's no installer and nothing goes in the registry. On Linux, extract the tarball and run ./OpenSave.

Windows SmartScreen may warn you, because the build isn't code-signed — certificates cost money this project doesn't have. More info → Run anyway if you're comfortable with that.

2

Click Auto-scan

OpenSave looks everywhere games actually keep saves — Steam libraries, Proton and Wine prefixes, emulator folders, the usual Windows locations — and checks them against a community-maintained list covering tens of thousands of titles. It takes a few seconds.

3

Or point it at a folder yourself

If a game isn't found, use + Track folder. This always works; auto-scan is only a convenience. Not sure where a game saves? PCGamingWiki lists save paths for most games.

The screen people get stuck on

Reading the scan results.

Why the date is the useful part

A game is often found in three or four places at once — the Steam folder, wherever your launcher put it, and one left behind by an install you've moved on from. They all look equally plausible. The date tells you which one you're actually playing.

“found in 3 folders”

When a game turns up in several places you get one tile, with that line underneath. Click it and each folder is labelled:

Label What it means Ticked?
the save folder The one to track — the folder with the most recent files Yes
part of the same save Sits beside it and holds another piece of the same save — settings, mods, profiles. Tracked together as one game Yes
another copy The same game somewhere unrelated. Usually a leftover from an old install No
already inside the folder above Covered already. Can't be ticked — two entries over the same files would fight No

The Track button does whatever is ticked. If two folders are one save it says Track all 2 and creates a single game with both. If OpenSave picked wrong — you know the old-looking one is the one you play — just open the list and tick that instead.

Empty folders are hidden

Steam creates a save folder for every game you own, whether or not saves go there, so a real scan is full of folders with nothing in them. Those are hidden by default — on a typical library that's about a fifth of the results. Tick Show N empty in the toolbar if you want to track a game before playing it for the first time.

The point of all this

Adding your second device.

🏠

Same network

Open Devices on both — they find each other automatically. Click Pair on one and approve it on the other. Pairing is mutual on purpose: nobody connects to your machine without you saying yes on that machine.

Not seeing each other? Your network is probably set to Public, which blocks local discovery. Set it to Private, allow OpenSave through the firewall, or skip discovery entirely with Devices → Add by IP address.

🌍

Different networks

Open Internet Sync, generate a room code, and enter the same code on the other device. They find each other through a relay — no port forwarding, no router settings. The relay only passes along encrypted data; it can't read your saves and doesn't store them.

Treat the room code like a password. Anyone who has it can send your devices a pairing request — though they still can't sync anything without you approving it.

Once paired, tracked games sync on their own. Both devices need to be tracking the same game for it to sync — if a title is named differently on each machine, OpenSave can usually match them by Steam App ID, or you can link them by hand.

When it goes wrong in-game

Getting an old save back.

Open a game from the sidebar. The Snapshots tab lists every version, newest first.

⏪

Restore

Put the whole save back to how it was. Your current state is snapshotted first, so a restore is always reversible.

📄

Browse files

Look inside a snapshot and restore a single file out of it, leaving everything else alone.

📌

Snapshot now

Take one deliberately, with a comment, before you try something risky.

🌱

Branches

A separate line of saves for the same game — New Game+ without losing your finished playthrough. Switching always snapshots the branch you're leaving first, so it can be undone by switching back.

How many are kept

Two separate allowances, so a game that autosaves constantly can't push out a snapshot you took on purpose. Automatic snapshots keep the newest 20 per branch by default. Manual ones — the ones you took yourself — are kept forever unless you say otherwise.

The situation everyone worries about

When two devices disagree.

Play on your desktop, then on your laptop before the first sync finished, and both have changes the other doesn't. OpenSave notices and stops.

It doesn't use timestamps to decide — clocks disagree between machines, and "newer" isn't the same as "the one you want". It tracks what the two devices last agreed on, and if both have moved since, that's a conflict. You get three choices:

💻

Keep mine

This device's version wins.

📡

Keep theirs

The other device's version wins.

🌿

Keep both

The other version goes onto a new branch, so nothing is lost. Pick this if you're not sure.

Nothing is overwritten until you choose. And if a game has several save folders, they're judged separately — a disagreement in your settings folder doesn't hold up your actual progress.

Two situations that trip people up

Games with awkward saves.

A save split across several folders

Some games keep progress in one place and settings or mods in another — TrackMania keeps Scores, Tracks and Profiles as three sibling folders. Auto-scan usually spots this and offers them together. To do it by hand: Configuration → Save locations.

Use the same name on your other devices. The name is what the two machines match on, because the folder itself lives somewhere different on each. Removing a location never deletes anything.

Files that shouldn't travel between machines

Some games store device-specific settings — resolution, controller bindings — right beside the save, and copying those to another machine can break the game there. Open Configuration → Files that shouldn't sync and either click Pick from your save folder to tick the file from a list, or type patterns like a .gitignore:

files that shouldn't sync
Config.gs a file of that name, anywhere /Config.gs only at the top level *.log anything ending .log logs/ a whole folder !keep.log an exception to a line above

Excluding a file never stops it being backed up. Snapshots still capture it and a restore brings it back — excluding only stops it travelling between machines. Set the same list on your other devices; each applies its own.

Easy to miss

A few things worth knowing.

🖥️

Closing the window doesn't quit

It hides to the system tray so syncing keeps running. Right-click the tray icon to reopen, sync everything, or actually quit.

🔗

Same game, different names

Tracked as "Elden Ring" here and "ELDEN RING" there? They won't sync — they're two games. Rename one, or link them.

📋

Activity

The log of everything OpenSave has done. The first place to look when something didn't happen and you want to know why.

🧳

Moving to a new PC

Pair the two and let them sync — or use Cloud Backup → Export to write your whole library to one portable file, and import it on the other side.

🛡️

Untracking is safe

Removing a game never deletes a save file or a snapshot. Nothing in OpenSave deletes a save except restoring over one — which snapshots first anyway.

🎮

Steam Deck

Install the background service once and it syncs in Game Mode without you thinking about it. There's a Decky plugin for status and a sync button.

When something looks wrong

The usual suspects.

My devices can't see each other

Set the network profile to Private, allow OpenSave through the firewall, and check both are on the same network. Failing that, use Devices → Add by IP address, or a room code under Internet Sync — which works even on the same network.

A game wasn't detected

Use + Track folder and point at it. Auto-scan covers a lot but can't cover everything. PCGamingWiki lists save paths for most games.

It found the game in the wrong place

Open found in N folders on the tile and pick the folder with a recent date. Already tracked the wrong one? Untrack it and track the right one — untracking never deletes saves.

My save didn't sync

Check both devices are tracking that game, that they show as paired under Devices, and that the game isn't waiting on a conflict. Activity usually says exactly why.

A folder shows as empty but I know it has saves

The scan hides folders with no files — tick Show N empty to see them. If a folder really does have files and still shows as empty, OpenSave couldn't read it; check permissions.

I restored the wrong snapshot

Restore again. Your pre-restore state was snapshotted automatically, so it's in the list.

"404 Not Found" when the app opens

Something else is using port 8383 — often a second copy of OpenSave still running. Check the system tray and Task Manager, or change the port under Settings → Advanced.

I want to start over

Untracking removes a game from your library and leaves every save file and snapshot on disk. Deleting the .opensave folder in your home directory resets everything and touches none of your actual game saves.
